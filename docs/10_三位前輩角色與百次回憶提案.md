# 三位前輩角色與百次回憶提案

- 狀態：`IMPLEMENTED`（v0.10.11，Claude Code 2026-09-26 實作並用瀏覽器測試；**擁有者尚未實際操作確認，不是 VERIFIED**）
- 記錄日期：2026-09-26
- 適用內容：第二台機台「三位前輩的考驗」

## 關係定位

- 玩家沒有固定性別。
- 三位前輩與玩家的核心關係都是信賴，不是戀愛。
- 岩倉、赤井與玩家是朋友關係；霧島是前輩對晚輩的關心。
- 赤井可以不分玩家性別稱玩家為「兄弟」。
- 岩倉服飾店劇情可以讓店員把玩家當成男性，不構成設定衝突；但不要把性別誤會寫成劇情重點。

## 角色正式設定

### 岩倉

- 女性，22 歲，168 公分、61 公斤，開朗的大姐型個性。
- 喜歡休假時買衣服、穿公主裙、把自己打扮得很漂亮。
- 原本想成為植物學家，但家人要求她工作；朋友已在礦坑工作，因此帶她進入礦坑。
- 16 歲開始下礦，至今工作六年。
- 是女同志，喜歡女性；礦坑同事不知道，只覺得她很有機會脫離單身。
- 激熱發展：和玩家外出買衣服，讓玩家看到她平常藏起來的少女心。

### 赤井

- 男性，24 歲，176 公分、48 公斤，瘦高。
- 家中總共有六個孩子；赤井本人加上五個弟弟妹妹。
- 父母很早在礦坑中離世。赤井相信自己進礦坑工作會受到父母保護，並以收入養活弟弟妹妹。
- 外在形象是會和朋友去酒吧喝酒、很會照顧大家；內心對家人非常細膩。
- 不喜歡別人同情他，也不希望玩家把他當成需要被拯救的人。
- 激熱發展：帶玩家回家，讓玩家看見家中六個孩子的真實生活。

### 霧島

- 男性，56 歲，158 公分、58 公斤，有肌肉，至今單身。
- 小時候夢想成為忍者。
- 父親過世後，11 歲便進入礦坑工作，扛起照顧家人與弟弟的責任。
- 在礦坑仍危險而嚴肅的年代長大，因此個性嚴格、幾乎不笑；談到童年時才會比較開心。
- 神社與信仰是支撐他活下去的力量。
- 激熱發展：帶玩家去神社；信任玩家後會對玩家露出真正的笑容。

## 各前輩成功 100 次

### 累積方式

- 分別永久記錄岩倉、赤井、霧島的「談話成功次數」。
- 只在該前輩的談話成功（`dateWin`）時加一；失敗、開始談話或 ST 通關都不計算。
- 進度不能存在離開礦坑就會清除的第二台暫時狀態中，必須跟著本機及雲端存檔永久保存。

### 玩家可見進度

- 在背包新增「前輩信賴」區塊，三位前輩各有一條 `目前次數／100` 的進度。
- 未完成時在進度下顯示：`獎勵：岩倉／赤井／霧島好像有話要跟你說……`
- 完成後改成：`已獲得：與○○的珍貴回憶`
- 不擠進礦坑上方原有的四項即時數據，避免戰鬥畫面過滿。

## 第 100 次的特別演出

1. 第 100 次談話成功後，先正常顯示成功結果並停止自動模式。
2. 立即進入該前輩的特別回憶；原本已進入的獎勵流程暫停顯示，但遊戲數值不重抽、不重算。
3. 上方原本顯示礦石名稱的大方塊改成可捲動的對話紀錄框。新台詞逐次追加，已出現的歷史台詞保留到本段演出結束。
4. 下方原本用來點擊挖礦的敘述框改成「點擊繼續」。最後一步改成明確的「收下回憶並繼續」。
5. 演出期間暫停自動挖礦，並避免離開礦坑、切換畫面或重複觸發造成進度遺失。
6. 玩家完成最後確認後，獲得唯一收藏道具，關閉特別演出，還原原本的大方塊與挖礦敘述框，接續先前已確定的遊戲獎勵流程。
7. 若演出中途關閉遊戲，下次進入時從尚未完成的位置恢復；收藏道具只在最後確認後發放一次。

### 收藏道具

- `與岩倉的珍貴回憶`
- `與赤井的珍貴回憶`
- `與霧島的珍貴回憶`

這三件道具放在背包獨立的「珍貴回憶」區塊，沒有價格、能力或消耗用途，不能出售、不能交委託，也不算礦石圖鑑。每件只能取得一次。

## 百次回憶的敘事方向

以下三個方向已獲擁有者喜歡，正式長篇台詞留待之後另行撰寫：

- 岩倉〈不想解釋的事〉：挑公主裙時向信得過的玩家說明自己喜歡女性，以及為什麼在男性居多的礦坑反而自在；最後用逼玩家認真挑衣服的玩笑收尾。
- 赤井〈五個安靜下來以後〉：五個弟弟妹妹睡著後談起父母與下礦原因；拒絕同情，但接受玩家幫最小的孩子補習這種平等而具體的小忙。
- 霧島〈另一枚手裡劍〉：在神社找到童年削的木製手裡劍，談到父親、11 歲下坑與弟弟；最後答應教玩家，露出前輩對晚輩的笑容。

正式演出可以比現有談話長，但每次點擊仍只追加一小段，避免手機畫面一次塞入長篇文字。

## 百次後的後續發展

- 取得某位前輩的珍貴回憶後，可解鎖該人的「深度信賴台詞池」或後續特殊演出。
- 後續台詞尚未撰寫，本次只預留是否已取得回憶的判斷入口，不自行生成大量台詞。
- 新台詞應補充既有人格，不覆蓋原有台詞，也不把信賴關係改寫成戀愛。

## 舊存檔處理

- 現有存檔只有當日總成功次數，沒有過去每位前輩各自成功幾次，因此功能上線時不猜測或回補。所有玩家從本功能上線後由 0 開始，介面註明「自此版本開始記錄」。

## 實作紀錄（v0.10.11）

- 存檔：`save.senpai = { since, wins:{a,b,c}, memories:{a?:{date,wins}}, story:{boss,step}|null }`，與離開礦坑就刪除的 `plays2` 分開。`newSave`、本機載入、`adoptSave`（雲端採用）、編輯模式匯入存檔都會經過 `fixSenpai()` 補齊／修復欄位。
- 計數：只在 `doSwing2` 處理 `dateWin` 事件時 `senpaiWin(boss)` 加一；達 `memories.need`（100）且尚未取得、沒有其他進行中的回憶時才設定 `story`。收藏以旗標記錄，不是數量，所以不可能重複發放。
- 台詞：`js/config.js` → `machine2.memories.{a,b,c}.lines`，依序追加；要加長直接往陣列後面加。
- 演出：`#scene` 加上 `story-on` 後顯示 `#storyLog`（可捲動、自動捲到最新）；敘述框顯示「▼ 點擊繼續」，最後一句後改「▼ 收下回憶並繼續」。演出中 `doSwing`／`doSwing2` 直接返回（不抽、不耗工具、不加揮數），自動、離開、前往其他礦坑都被擋下；切到背包等分頁可以，回來會恢復。
- 防誤觸：最後一句出現後 0.6 秒內的點擊不算確認；收下後 0.6 秒內的點擊不會直接揮出去。
- 收藏：背包「前輩信賴」與「珍貴回憶」兩個區塊；不進 `save.ores`／`save.dex`，出售、全部出售、委託、圖鑑都看不到。
- 百次後擴充入口：`hasMemory(boss)`（game.js 內部）與 `save.senpai.memories[boss]`。
- 開發者：`Game.m2.senpai("a", 99)` 可直接設定次數方便測試。
- v0.10.12：「前輩信賴」「珍貴回憶」兩個區塊從背包搬到新的「成就」書籤頁（底部導覽第 6 顆）；回憶收下後的提示改為「收在『成就』頁」。
