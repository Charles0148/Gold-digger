# 21｜頭銜系統規格

> 狀態：v1.02.00 IMPLEMENTED（2026-10-06）。實際數值以 `js/config.js` 的 `titles` 為準。

## 玩家看到的規則

- 頭銜顯示在玩家名字下方。**唯一可更換入口：點頂部玩家名字 → 帳號頁 → 換頭銜**（才可戴上／不戴頭銜）。
- 「紀錄 → 成就 → 頭銜」是純圖鑑：只看已取得／未取得、條件、進度與一句介紹，不能戴上或取消（程式以 `titleMode` 限制，`wearTitle`／`clearTitle` 也會擋）。
- 傳說名條平常完全靜止；玩家點一下名條，流光只掃過一次（`sweepTitle`，一次性 `.sweep` class）。
- 稀有度分為一般、珍貴、稀有、傳說。未取得的一般／珍貴／稀有頭銜會顯示條件與進度；未取得的傳說只顯示 `？？？`。
- 點頭銜可查看一句介紹。取得後永久保留，不會因進度下降而收回。
- 新玩家自動取得並戴上「新來的礦工」；舊存檔載入時會依現有資料補發可證明已達成的頭銜。玩家在帳號頁選「不戴頭銜」後會保持不戴（存成空字串），不會再被自動戴回。

## 新增存檔統計

`save.stat` 新增：總揮鎬數、各礦坑揮鎬數、累計登入天數、最後計入登入的台灣日期、完成委託數、用壞鎬子數、一般／前輩台地底凍結次數、進入「前輩的心意」次數。`save.titles` 保存已取得與目前使用中的頭銜。

舊存檔沒有歷史資料可證明的次數型項目從 0 開始；既有解鎖、圖鑑、前輩談話、珍貴回憶與恩惠資料則可直接補發。登入只在可信台灣日期可用時每天加一次。

## 本版邊界

- 「掌心有紅光」與「衣櫃裡有礦味」先保留規格；`main` 尚未加入紅晶／外觀半成品，因此目前不會誤解鎖。
- 6 款成就版外觀的取得方式尚未定案，本版不實作。
- 本版不含 `ruby-wip` 的任何紅晶程式。
