# 深層礦脈｜試玩回饋表

感謝幫忙試玩！不用懂程式，照你的直覺回答就好。

## 怎麼玩

1. 用手機打開遊戲網址，輸入名字。
2. 點畫面下方的**敘述框**，每點一下就揮一次鎬子。
3. 出現「≋ 地鳴 ≋」時，敘述框的**邊框顏色**代表期待度：藍 < 黃 < 綠 < 紅，彩色最強。
4. 挖到「小礦脈／大礦脈／星辰礦脈」之後，會連續挖到很值錢的脈晶；礦脈中挖到金礦有機會讓礦脈延伸。
5. 挖到的礦石拿去給**老闆（佐佐木）**：可以直接賣，或交付「委託板」上要的礦石拿 1.5 倍的錢和恩惠點數，升級會得到永久加成。錢夠了可以到**地圖**解鎖更深的礦坑。
6. 右下角可以切換**手動／自動**。
7. 請不要按左上角的 ✎，那是開發用的編輯模式。

建議至少玩 **15 分鐘**，或是玩到挖到一次礦脈。
