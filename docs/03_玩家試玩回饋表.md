# 深層礦脈｜試玩回饋表

感謝幫忙試玩！不用懂程式，照你的直覺回答就好。

## 怎麼玩

1. 用手機打開遊戲網址，輸入名字。
2. 點畫面下方的**敘述框**，每點一下就揮一次鎬子。
3. 敘述框的**邊框顏色**代表期待度：白 < 綠 < 藍 < 紫 < 金 < 彩虹。
4. 出現「RB／BB／SBB」之後進入 AT，會連續挖到很多好礦；AT 中挖到金礦有機會連莊。
5. 挖到的礦石到**背包**賣掉換錢，再到**工坊**買新工具。錢夠了可以到**地圖**解鎖更深的礦坑。
6. 右下角可以切換**手動／自動**。
7. 請不要按左上角的 ✎，那是開發用的編輯模式。

建議至少玩 **15 分鐘**，或是玩到出現一次 AT。
