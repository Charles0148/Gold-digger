# 深層礦脈｜脈絡總覽 v0.1

> 給所有人看的版本：這款遊戲是什麼、怎麼玩、SLOT 的機制怎麼對應到挖礦。
> 懂程式的 AI 請接著看 `02_AI驗證用技術規格.md`；試玩的朋友請看 `03_玩家試玩回饋表.md`。
> 暫定名稱「深層礦脈」，可以在編輯模式裡改。

---

## 1. 一句話

**一款手機直式、以文字為主的挖礦遊戲。玩家點一下敘述框就揮一次鎬子，背後的抽選方式照搬日本 SLOT（スマスロ）。** 定位是上班時殺時間用的遊戲，主要樂趣是累積財富和收集圖鑑。

### ⚠ Claude 自行假設、需要確認的部分

1. **主角**：我把「主角就是你自己」理解為「玩家本人」。如果你的意思是「主角是 Claude」，之後可以加一個角色。
2. **礦坑的深淺**：「越深越好」做成 5 座礦坑，越深的礦坑需要越高階的工具，售價也越高。
3. **設定每天換**：每座礦坑每天（依手機日期）分配一次設定，同一天內不變，類似店家每天改設定。
4. **鍛造升級**：每種工具最多升 5 級，每級耐久 +10%；所有工具的等級加總後，每級讓全部礦石售價 +2%。
5. **廣告**：看一次廣告送一把木鎬，每天最多 10 次。目前是 5 秒倒數的示意畫面。
6. **新手資源**：初始資金 $300 + 兩把木鎬。
7. **遊戲名稱「深層礦脈」、所有礦石與礦坑名稱**都是暫定。

## 3. 遊戲流程

```
        ┌──────────── 工坊：買工具／看廣告／升級 ◄────┐
        ▼                                              │
  背包裡有工具（可挖次數 = 耐久加總）                  │
        │                                              │
        ▼                                              │
  地圖：選礦坑（今天的設定是 1～6 之一，看不到）       │
        │                                              │
        ▼                                              │
  挖礦：點敘述框 → 揮一次 → 扣 1 耐久 → 得到礦石       │
        │           └→ 敘述框顏色暗示期待度            │
        │           └→ 當選 → 前兆 → 礦脈（大量好礦）  │
        ▼                                              │
  背包：賣礦石換錢、圖鑑登錄新礦石  ──────────────────┘
```

## 4. SLOT → 挖礦 對照表

| SLOT 用語 | 遊戲中 | 說明 |
|---|---|---|
| 投幣 / 1 遊戲 | 揮一次鎬子 | 扣工具 1 點耐久 |
| 小役 | 挖到的東西 | 碎石／普通／優良／稀有／史詩／傳說 6 種 |
| 內部抽選 | 每揮一次在背後抽 | 抽到的小役決定這一揮有沒有當選礦脈 |
| 通常狀態 | 通常 | 當選率低 |
| 高確 | 高確 | 當選率大約是通常的 10 倍，平均約 10 揮後回到通常。偶爾出現「空氣變得潮濕了」的暗示 |
| 前兆 | 前兆 | 當選後持續 3～8 揮，敘述框顏色偏高 |
| ガセ前兆 | 假前兆 | 沒當選卻出現 2～6 揮的前兆演出 |
| AT / BONUS | **礦脈** | 25 揮，好礦大量出現 |
| 連荘 / 引き戻し | 礦脈延續 | 礦脈結束時抽延續率（設定1 28% ～ 設定6 36%） |
| 天井 | 天井 | 800 揮沒當選，必定當選 |
| 設定 1～6 | 礦坑今天的設定 | 越高越好；**史詩礦的出現率**有設定差，可以用來推測設定 |
| 液晶演出期待度 | 敘述框邊框和文字顏色 | 白 < 綠 < 藍 < 紫 < 金 < 虹（虹 = 確定） |
| 資料機台 | 礦坑資訊列 | 本日揮數、礦脈次數、史詩次數、距上次礦脈的揮數 |
| 機械割 | 機械割 | 挖到的價值 ÷ 工具花費；100% 以上代表玩家賺 |

## 5. 目前的機率成果（模擬 300 萬揮 × 6 個設定）

**淺層洞窟（第 1 層）**

| 設定 | 初當 | 機械割 | 平均連 | 天井到達率 |
|---|---|---|---|---|
| 1 | 1/302 | 95.9% | 1.39 | 8.2% |
| 2 | 1/285 | 99.3% | 1.42 | 6.9% |
| 3 | 1/277 | 99.6% | 1.42 | 6.1% |
| 4 | 1/251 | 104.4% | 1.46 | 4.4% |
| 5 | 1/232 | 108.9% | 1.50 | 3.0% |
| 6 | 1/211 | 114.2% | 1.56 | 2.1% |

**期待度顏色**：出現這個顏色時，真的在前兆中的比例（設定1）

| 白 | 綠 | 藍 | 紫 | 金 | 虹 |
|---|---|---|---|---|---|
| 0.4% | 7.1% | 21.2% | 47.5% | 90.7% | 100% |

設計重點：

- **設定1 小虧，設定6 小賺**，和真實 SLOT 的感覺接近，玩家有動機去找高設定的礦坑。
- 深層礦坑的機械割高約 5%，當作進度獎勵，原因是工具掉落的價值比較高。
- 數字全部可以在編輯模式的「數值」分頁修改，改完到「模擬」分頁跑一次就能看到新結果。

## 7. 編輯模式（你的主要工作台）

| 分頁 | 可以做的事 |
|---|---|
| 版面 | 開啟點選模式 → 點畫面上任何虛線區塊 → 拖曳移動，調整寬高、字級、圓角、顏色，也可以隱藏 |
| 顏色 | 介面主題色、6 種稀有度的顏色和名稱、期待度顏色 |
| 圖片 | 背景、敘述框、每座礦坑的場景、每把工具的圖示，都可以上傳圖片 |
| 文字 | 所有演出文字、礦坑名稱、礦石名稱、工具名稱 |
| 數值 | 所有機率表、工具價格、耐久、礦坑倍率 |
| 模擬 | 一鍵跑設定1～6，看初當、機械割、期待度，並可複製結果給別人驗證 |
| 存檔/測試 | 下載或匯入設定檔、顯示今天的設定、強制設定、加錢加工具、下載或刪除存檔 |

**合作流程**：在編輯模式調整 → 下載 `mine-config.json` → 放進「挖礦遊戲」資料夾 → 跟 Claude 說「套用設定檔」→ Claude 寫回正式程式。
