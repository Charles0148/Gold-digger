## 1. 一句話

**一款手機直式、以文字為主的挖礦遊戲。玩家點一下敘述框就揮一次鎬子，背後的抽選方式照搬日本 SLOT（スマスロ）。** 定位是上班時殺時間用的遊戲，主要樂趣是累積財富和收集圖鑑。

## 2. 決策紀錄（諾茲托特已確認）

| # | 題目 | 決定 |
|---|---|---|
| Q1 | SLOT 機制 | 內部抽選、狀態（通常/高確/前兆/AT）、天井、設定1～6、期待度顏色 |
| Q2 | 點擊方式 | 點一下揮一次（手動），可切換成自動連續挖、遇到演出就停 |
| Q3 | 目標 | 圖鑑收集 + 累積財富，定位為殺時間 |
| Q4 | 「投幣」 | 工具耐久度：揮一次扣 1 點，歸零就壞掉。工具可以挖到，也可以購買 |

| # | 題目 | 決定 |
|---|---|---|
| T1 | 用語 | 畫面上**不直接出現**「前兆／AT／RB／BB」等術語。前兆期間顯示「≋ 地鳴 ≋」標籤；RB／BB／SBB 分別叫「小礦脈／大礦脈／星辰礦脈」；連莊叫「礦脈延伸」 |

| T6 | 礦脈中的礦石 | 另外設計「脈晶」礦石，價格高很多，也收進圖鑑；平常的礦石變便宜 |

### 第四輪決策（v0.4：礦坑老闆 佐佐木）

| # | 題目 | 決定 |
|---|---|---|
| F1 | 老闆 | 一位老闆「佐佐木」，取代原本的工坊。文字遊戲式對話框（名牌＋台詞，沒有立繪），選項：看委託板／賣礦石／買鎬子／我的恩惠／領補給（廣告）／離開 |
| F2 | 賣礦石 | 只能在老闆那裡賣；背包只看不賣 |
| F3 | 委託板 | 每 **8 小時**換一張，1～3 項礦石；可能要求還沒去過的礦坑的礦石。沒挖過的礦石顯示「？？？」；挖過的點名稱會跳出產地。交付按鈕上顯示「包包 有幾個／需要幾個」 |
| F4 | 交付獎勵 | 每項給**基本售價 × 1.5 倍**的錢＋恩惠點數（普通2／綠3／藍4／紫6／金8，整張完成再 +1） |
| F5 | 恩惠等級 | Lv1～4 每級 25 點、Lv5～9 每級 35 點、Lv10～14 每級 45 點，每 5 級 +10。平均一張委託約 7 點（約 3～4 張升一級） |
| F6 | 恩惠 | 每升一級抽一個永久加成，稀有度 普通60%／藍28%／紫10%／金2%，可無限疊加、沒有保底，**不會改變任何抽選機率**。普通：看廣告多拿 1 把木鎬、恩惠點數 +10%、自動速度 +5%；藍：指定礦石售價 +5%、工具掉落率 +10%、委託數量 -5%；紫：指定稀有度售價 +3%、新工具耐久 +3%、看廣告 5% 多拿石鎬；金：全部礦石售價 +1%、買鎬子 -1% |
| F7 | 工具限制 | 取消「要幾階以上才能挖」。低階工具挖高階礦坑：收益 ×（工具每揮成本 ÷ 該礦坑對應工具每揮成本）× 0.9，做法是礦石有機率「碎掉」（工具掉落也一樣打折）。高階工具挖低階礦坑收益不變 |
| F8 | 礦坑差距 | 礦坑售價倍率縮小成 1／1.5／2.2／3／4，像挑 SLOT 機台一樣沒有巨大匯率差；工具價格一起調整，機械割不變 |
| F9 | 解鎖費用 | 煤灰坑道 300、鏽鐵礦山 1,000、熔岩深淵 3,000、星核裂谷 8,000 |
| F10 | 移除 | 鍛造升級、背包賣礦按鈕 |
| F11 | 機械割 | 只算礦坑基本期望值（用對應階級的工具、不含恩惠），玩家自己賺到的加成不算進去 |
| F12 | 之後再做 | 工具隨機詞條；後期花錢的地方（例如看得到設定的眼鏡、會嗅出紫以上礦石的寵物蛋） |

### 第五輪決策（v0.5：連續演出改版）

參考日本實機（擬似連、ステップアップ、チャンスアップ、復活）的做法。

| # | 題目 | 決定 |
|---|---|---|
| G1 | 何時決定 | **進入連續演出的瞬間**就決定回合數（1～5）與最後會不會通關；之後的演出只負責表現 |
| G2 | 回合數＝期待度 | 回合數越多通關率越高：設定1 約 6%／15%／35%／60%／90%。回合數少的出現機率高，長的很少見 |
| G3 | 劇本 | 每種回合數有自己的劇本，內容是「往礦坑深處走」：礦道變窄 → 翻倒的礦車 → 探險包裡的手繪地圖 → 綠色火焰的油燈 → 被封住的木門。通關＝門後是沒被挖過的礦脈；失敗＝坑道坍塌 |
| G4 | 顏色 | 文字與邊框顏色**只會往上升，不會掉下去**。第 1 回合從白或藍開始，最後一回合的顏色由「會不會通關」決定 |
| G5 | 顏色的可信度 | 藍約 8%、黃約 12%、綠約 21%、紅約 77%（也就是紅色大約四分之一會失敗，藍色大約一成會過） |
| G6 | 機會牌升格 | 演出中挖到**紫礦**→ 通關率往上一階並重抽一次，顏色至少升到綠；挖到**金礦**→ 直接通關確定，顏色至少升到紅 |
| G7 | 復活 | 已經通關的演出，有 20% 會先演成「坍塌失敗」，下一揮才拉回來（「塌落的縫隙裡透出光」）。另外金礦在最後一回合進來也算當場救回 |

### 4.1 一次揮擊的流程

```
通常／高確
 ├─ 金礦 ─┬─ 20%（高確30%）→ 直擊 → 前兆1揮 → AT
 │         └─ 沒直擊 → 抽演出長度 ─┬─ 1揮：結束
 │                                  └─ 2～5揮：連續演出
 ├─ 紫礦 ─ 通常15%／高確45% → 連續演出（2～5揮）

 └─ 累計達天井 → 前兆（3～8揮）→ AT

連續演出（進入時就決定，v0.5）
 抽回合數 1～5（金礦觸發比較容易抽到長的）

AT 中每一揮（還沒確定下一隻時，v0.6）
```

### 4.2 地鳴與期待度顏色

- 進入前兆、連續演出、假前兆時，敘述框上方出現「**≋ 地鳴 ≋**」，並顯示「……腳下傳來低沉的地鳴」。三種情況看起來一樣，玩家分不出真假。
- **連續演出中（v0.5）**：進入時就排好一條「只升不降」的顏色路線，最後一回合的顏色由會不會通關決定。實際可信度：藍 8%、黃 12%、綠 21%、紅 77%。
- **前兆**：綠、紅為主。**假地鳴**：沒有任何抽選 → 只會出藍、黃。
- **彩色**：只在已確定 SBB 時抽選（約 40%），從某一揮開始變彩色並持續到揭曉。
- **金色**：復活演出專用，出現就是確定當選（該次已排定彩色時仍然顯示彩色）。
- 平常沒有地鳴時，邊框一律白色。

### 4.3 違和感（確定演出）

出現時機只有三種：①已確定礦脈的前兆中 ②連續演出中已當選之後 ③礦脈中已確定延伸但還沒告知時。**出現就是確定**，種類偏向下一隻是小／大／星辰礦脈。

| 紋路發光 | 出現「岩壁上的紋路亮了一下」 | **大礦脈** |
| 點擊提示變化 | 右下「▼ 點擊」變成「▽ 點擊」 | **大礦脈** |
