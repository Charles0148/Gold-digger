# 深層礦脈｜脈絡總覽 v0.4

> 給所有人看的版本：這款遊戲是什麼、怎麼玩、SLOT 的機制怎麼對應到挖礦。
> 懂程式的 AI 請接著看 `02_AI驗證用技術規格.md`；試玩的朋友請看 `03_玩家試玩回饋表.md`。
> 暫定名稱「深層礦脈」，可以在編輯模式裡改。

---

## 1. 一句話

**一款手機直式、以文字為主的挖礦遊戲。玩家點一下敘述框就揮一次鎬子，背後的抽選方式照搬日本 SLOT（スマスロ）。** 定位是上班時殺時間用的遊戲，主要樂趣是累積財富和收集圖鑑。

| # | 題目 | 決定 |
|---|---|---|
| F1 | 老闆 | 一位老闆「佐佐木」，取代原本的工坊。文字遊戲式對話框（名牌＋台詞，沒有立繪），選項：看委託板／賣礦石／買鎬子／我的恩惠／領補給（廣告）／離開 |
| F2 | 賣礦石 | 只能在老闆那裡賣；背包只看不賣 |
| F3 | 委託板 | 每 **8 小時**換一張，1～3 項礦石；可能要求還沒去過的礦坑的礦石。沒挖過的礦石顯示「？？？」；挖過的點名稱會跳出產地。交付按鈕上顯示「包包 有幾個／需要幾個」 |
| F4 | 交付獎勵 | 每項給**基本售價 × 1.5 倍**的錢＋恩惠點數（普通2／綠3／藍4／紫6／金8，整張完成再 +1） |
| F5 | 恩惠等級 | Lv1～4 每級 25 點、Lv5～9 每級 35 點、Lv10～14 每級 45 點，每 5 級 +10。平均一張委託約 7 點（約 3～4 張升一級） |
| F6 | 恩惠 | 每升一級抽一個永久加成，稀有度 普通60%／藍28%／紫10%／金2%，可無限疊加、沒有保底，**不會改變任何抽選機率**。普通：看廣告多拿 1 把木鎬、恩惠點數 +10%、自動速度 +5%；藍：指定礦石售價 +5%、工具掉落率 +10%、委託數量 -5%；紫：指定稀有度售價 +3%、新工具耐久 +3%、看廣告 5% 多拿石鎬；金：全部礦石售價 +1%、買鎬子 -1% |
| F7 | 工具限制 | 取消「要幾階以上才能挖」。低階工具挖高階礦坑：收益 ×（工具每揮成本 ÷ 該礦坑對應工具每揮成本）× 0.9，做法是礦石有機率「碎掉」（工具掉落也一樣打折）。高階工具挖低階礦坑收益不變 |
| F8 | 礦坑差距 | 礦坑售價倍率縮小成 1／1.5／2.2／3／4，像挑 SLOT 機台一樣沒有巨大匯率差；工具價格一起調整，機械割不變 |
| F9 | 解鎖費用 | 煤灰坑道 300、鏽鐵礦山 1,000、熔岩深淵 3,000、星核裂谷 8,000 |
| F10 | 移除 | 鍛造升級、背包賣礦按鈕 |
| F11 | 機械割 | 只算礦坑基本期望值（用對應階級的工具、不含恩惠），玩家自己賺到的加成不算進去 |
| F12 | 之後再做 | 工具隨機詞條；後期花錢的地方（例如看得到設定的眼鏡、會嗅出紫以上礦石的寵物蛋） |

### ⚠ Claude 自行假設、需要確認的部分

1. **主角**：我把「主角就是你自己」理解為「玩家本人」。如果你的意思是「主角是 Claude」，之後可以加一個角色。
2. **礦坑的深淺**：「越深越好」做成 5 座礦坑，越深的礦坑需要越高階的工具，售價也越高。
3. **設定每天換**：每座礦坑每天（依手機日期）分配一次設定，同一天內不變，類似店家每天改設定。
4. ~~鍛造升級~~：v0.4 已移除，改為佐佐木的恩惠系統。
5. **廣告**：看一次廣告送一把木鎬，每天最多 10 次。目前是 5 秒倒數的示意畫面。
6. **新手資源**：初始資金 $300 + 兩把木鎬。
7. **遊戲名稱「深層礦脈」、所有礦石與礦坑名稱**都是暫定。

### 4.1 一次揮擊的流程

```
通常／高確
 ├─ 金礦 ─┬─ 20%（高確30%）→ 直擊 → 前兆1揮 → AT
 │         └─ 沒直擊 → 抽演出長度 ─┬─ 1揮：結束
 │                                  └─ 2～5揮：連續演出
 ├─ 紫礦 ─ 通常15%／高確45% → 連續演出（2～5揮）
 ├─ 其他 ─ 極低機率 → 連續演出
 └─ 累計達天井 → 前兆（3～8揮）→ AT

連續演出（每揮）
 當選率 = 基本14% ＋ 挖到紫35% ＋ 挖到金75%
 最後一揮揭曉：當選 → AT（紫帶當選 SBB 3%、金帶當選 SBB 6%）

AT 中挖到金礦
 └─ 已有下一隻 → 抽升格（RB→BB 約50%、BB→SBB 約10%）

AT 中每一揮（還沒確定下一隻時）
 延伸當選率 = 基本機率（依種類、設定）＋ 挖到藍／紫／金的加成
 → 當選：下一隻 BB80/RB15/SBB5
 第 1～4 隻：整體通過率 設定1 約 45%（RB 35%／BB 48%／SBB 約 78%）
 第 5 隻起：整體通過率 設定1 約 80%（RB 64%／BB 77%／SBB 約 95%），稀有礦加成約 2～3 倍
 告知：50% 當下演出，其餘到最後一揮才揭曉
```

### 4.2 地鳴與期待度顏色

- 進入前兆、連續演出、假前兆時，敘述框上方出現「**≋ 地鳴 ≋**」，並顯示「……腳下傳來低沉的地鳴」。三種情況看起來一樣，玩家分不出真假。
- 地鳴期間，每揮邊框顏色依**這一揮實際的抽選狀況**，從不同的權重表抽選（藍／黃／綠／紅）：
  - 假地鳴：沒有任何抽選 → 只會出藍、黃
  - 連續演出中、這一揮當選率低（< 30%）且沒中 → 以藍、黃為主，少量綠，不會出紅
  - 連續演出中、這一揮當選率高（≥ 30%，例如挖到紫、金）但沒中 → 可能出綠、紅
  - 已當選、確定前兆 → 綠、紅為主
  - 結果：**紅色只會出現在「已當選」或「高機率抽選」的時候**
- **彩色**：只在已確定 SBB 時抽選（約 40%），從某一揮開始變彩色並持續到揭曉。
- 平常沒有地鳴時，邊框一律白色。

### 4.3 違和感（確定演出）

出現時機只有三種：①已確定礦脈的前兆中 ②連續演出中已當選之後 ③礦脈中已確定延伸但還沒告知時。**出現就是確定**，種類偏向下一隻是小／大／星辰礦脈。

| 暗示 | 表現 | 偏向 |
|---|---|---|
| 音效異常 | 揮擊音變成「……鏗？」 | 小、大 |
| 水滴聲 | 出現「遠處傳來水滴聲」 | **小礦脈** |
| 紋路發光 | 出現「岩壁上的紋路亮了一下」 | **大礦脈** |
| 點擊提示變化 | 右下「▼ 點擊」變成「▽ 點擊」 | **大礦脈** |
| 無聲 | 揮擊音變成「……」 | **星辰礦脈** |
| 邊框金閃 | 敘述框邊框閃金色 | 星辰、大 |

**解讀**：設定1 玩 300 揮只有約兩成的人賺錢，而且大多只拿回四成左右；要玩到上萬揮才接近打平。設定6 玩到 3,000 揮以上才明顯賺錢。這符合「短期要靠運氣，長期一直玩才會賺」。
