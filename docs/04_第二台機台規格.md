> 這座礦坑用的是**獨立的引擎**（`js/engine2.js`），跟前五座礦坑完全不共用抽選邏輯。

## 2. 三位前輩

| 前輩 | 個性 | 紫機會牌 | 出現率 | 金機會牌 | 約會通過率（設定1→6） | ST 對應牌通過率 |
|---|---|---|---|---|---|---|
| 岩倉（好過） | 女生，容易被逗笑。**認真想教你東西**就是升溫 | 岩倉的礦燈 | 1/133 | 岩倉的金牌 1/833 | 45% → 49% | 90% → 92% |
| 赤井（中間） | 年輕男生，講話口語。**把你當兄弟／哥們**就是升溫 | 赤井的鑿子 | 1/300 | 赤井的金鑿 1/1667 | 55% → 59% | 80% → 84% |
| 霧島（最難） | 不苟言笑。**他笑出來**就是確信度最高 | 霧島的懷錶 | 1/741 | 霧島的金錶 1/4167 | 70% → 74% | 70% → 76% |

台詞分三層：`chat`（一般）、`up`（升溫，綠色時用）、`hot`（確信，紅色時用），每層可放多句隨機挑。

- 三種機會牌是**獨立礦石**，跟前五座礦坑的紫礦／金礦沒有任何關係。
- 三位前輩的累積數與好感度**各自獨立**，而且**玩家完全看不到**。

## 3. 流程

```
通常：每揮抽小役
  紫機會牌 → 該前輩好感度 +1~10%（抽選）
  金機會牌 → 對應的前輩們好感度 +5~30%（抽選，保底 5%）
      甲的金 → 甲＋丙；乙的金 → 乙＋丙；丙的金 → 甲＋乙＋丙
  加完之後，立刻用「好感度」當機率抽「前輩找你談話」
      例：+5% → 抽 5% 沒中 → 之後 +7% → 抽 12% → ……一直到 100% 必定被找
  好感度 100% → 必定被找，而且該次約會必定過關
  好感度永久保留；離開礦坑 → 全部歸零
  若同一轉有兩位以上當選 → 先當選的先約會；失敗立刻接下一位（「○○也想找你聊聊」）
      成功時只有成功那位歸零，另一位的好感度保留

談話（約會）：長度 5～15 轉的對話演出（不吃耐久、不給礦石）
  成功率 = 該前輩自己的通過率（好感度只影響「被不被找」，不影響這裡）
  長度 1～2 轉 或 16～20 轉 = 違和感 → 確定過關（只在會過時才會出現，約 12%）
  每一轉抽一個「信賴度顏色」：白／藍／黃 → 一般台詞、綠 → 升溫台詞、紅 → 確信台詞
  紅色越多越容易過關（實測 0 次紅 9%、1 次 39%、2 次 86%、3 次以上 97% 以上）
  失敗 → 好感度保留（繼續累積）
  成功 → 該前輩好感度歸零 → 進入報酬，並把這一輪的所有狀態（關數、上位、對手）重算

報酬（AT）：10 轉，只賺錢（挖到的礦石只能賣）

ST 挑戰（最多一直連下去）：
  三位前輩走出來，隨機一位出現（上位時由玩家選）
  10 轉內抽到「對應的機會牌」→ 依前輩通過率抽選（90/80/70%）
  抽到別人的機會牌 → 25%（設定6 30%）
  抽到**任何一張金機會牌 → 直接過關（確定）**，上位中也一樣
  10 轉內沒過 → 結束，回到通常

通過 → 一轉定勝負（決定 BONUS 轉數）
  一般：無 10～20 轉／銅鐘・空掘 18～50 轉／紫機會牌 45～100 轉／**金機會牌 100～300 轉**
  上位：無 30～55 轉／銅鐘・空掘 45～80 轉／紫機會牌 70～100 轉／**金機會牌 150～300 轉**（保底 30 以上）

告知方式（玩家選）：
  強力鑽頭 → 直接告知轉數
  鏟子 → 點按次數隨轉數變化（大約 6～18 下），每下挖出 +N
      一下挖多少 = 單位 × 1／2／3／5（權重 50/28/14/8），單位 = 轉數 ÷ 20（最少 1）
      例：28 轉 → 單位 1 → 約 15 下，中間會夾雜 +3、+5
          176 轉 → 單位 8 → 約 12 下，會出現 +24、+40
      每個 +N 會散落在場景框的不同位置，不會重疊
  ※ 兩種一定導向同一個轉數（內部先決定，演出只是表現）

BONUS：純增，只賺錢（每轉挖到 1～3 個礦石，權重 30/40/30）
  BONUS 裡的機會牌只代表更多錢，不做任何抽選
  → 結束後回到 ST 挑戰（第 n+1 關）
```

## 4. 上位（取得三位前輩的認可）

- **抽選時機：通關第 1／3／7／10 關「之後」**（準備下一關時才抽、才演出），所以第一關絕對不會直接是上位。機率 15%／10%／60%／100%（設定6 為 22%／17%／72%／100%）。
- 每次進 AT 都會把關數與上位狀態重算，所以「上次打到 10 關」不會讓下一次的第一關直接上位。
- 上位之後：
  - 每次 BONUS 結束都可以**自己選前輩**挑戰（「A前輩，這次我要得到你的信任」）。
  - 壓對 → 通過率 90%；壓錯 → 70%。
  - 三種機會牌出現率變成 **1:1:1**（各 8%）。
  - ST 失敗才結束。

## 5. 收益（機械割的計算基礎）

礦石分成**三組，完全不重疊**（再乘礦坑倍率 2.2）：

| 階段 | 礦石 | 基本售價 |
|---|---|---|
| 通常 | 碎鐵砂／廢礦渣（普通礦）、前輩的舊釘（空掘） | 0.5 |
| 通常 | 工班的徽章（銅鐘） | 1 |
| 通常 | 岩倉的礦燈／赤井的鑿子／霧島的懷錶（紫機會牌） | 2.5／4／7.5 |
| 通常 | 岩倉的金牌／赤井的金鑿／霧島的金錶（金機會牌） | 6／9／15 |
| 報酬10轉・ST・一轉定勝負 | 工棚的鐵屑／工班的鑰匙 | 1.5 |
| 報酬10轉・ST・一轉定勝負 | 班長的筆記 | 3 |
| 報酬10轉・ST・一轉定勝負 | 岩倉／赤井／霧島的信任 | 6／8／12 |
| 報酬10轉・ST・一轉定勝負 | 岩倉／赤井／霧島的肯定（金機會牌） | 15／18／25 |
| **只在 BONUS** | 零錢袋／工資袋 | 3.85 |
| **只在 BONUS** | 加班費 | 7.7 |
| **只在 BONUS** | 岩倉／赤井／霧島的紅包 | 12.1／15.4／22 |
| **只在 BONUS** | 岩倉／赤井／霧島的獎金袋 | 30.25／38.5／52.25 |

**現金類的高價礦石（紅包、獎金袋、加班費、工資袋、零錢袋）只會在 BONUS 出現**，通常時、報酬 10 轉、ST、上位 ST 都不會挖到。已用實機測試驗證：各階段挖到的礦石名稱完全分開。

- v0.9.2 調整：礦石拆成三組（通常／報酬・ST／BONUS），高價現金類只留在 BONUS。BONUS 每轉的期望收入約是通常的 20 倍以上。
- 機械割 = (礦石基本售價 × 礦坑倍率) ÷ 工具花費，**只用上面的基本價**算，不含恩惠、委託 1.5 倍、廣告。
- 演出轉（約會對話、挑戰準備、選擇、鏟子點按）**不消耗耐久、不產生礦石**。

## 6. 實作與驗證

- 引擎：`js/engine2.js`（`newState2` / `step2` / `simulate2`），與 `engine.js` 完全獨立。
- 狀態：`normal / date / at / stIntro / st / reward / pick / dig / bonus`，存在 `save.plays2[礦坑id]`。
- 已驗證：
  - 40 萬次報酬抽選中，鏟子告知的轉數與內部決定的轉數 **100% 一致**（不會出現鑽頭 200 轉、鏟子 189 轉的情況）。
  - **自動模式在演出開始時會自動暫停**（談話開始、也想找你聊聊、上位、選擇前輩、選擇告知方式、一轉定勝負、ST 失敗）。玩家可以自己點著看，或再按一次自動＝快速跳過。
  - 離開礦坑後 `save.plays2` 該座的狀態整個刪除（累積、好感度全歸零）。
- 已驗證：ST 中抽到金機會牌 198 次，通關率 100%；鏟子挖出的總和與內部轉數 100% 一致。
- 已驗證：違和感長度（1～2 轉或 16～20 轉）**100% 都是會過的場合**；50 萬轉中出現率約 3.5%（佔會過場次的 12%）。
- 模擬（每設定 90 萬抽選轉，v0.9.2）：設定1 RTP 104.8%、初當 1/370、平均通關 3.30 關；設定6 RTP 138.6%、初當 1/357、平均通關 4.63 關。
- 為了平衡「金機會牌確定過關 + 100～300 轉」，AT／ST／BONUS／一轉定勝負裡的金機會牌出現率降為原本的 40%（通常時維持不變，因為那是好感度的來源）。

## 7. 離開礦坑

挖礦畫面右下角有「離開」按鈕，會先問：

> 真的要離開嗎
> 離開了礦坑之後，坑洞將會坍塌，搜尋的結果也將重置喔…

按「離開」→ 該礦坑的狀態（機會牌累積、好感度、本日數據、第一台的天井累積）整個刪除，回到地圖。按「留下」→ 什麼都不會變。

## 7b. 進入密碼（上鎖）

這座礦坑要輸入密碼才能進入，地圖上的「前往」會顯示 🔒。開鎖成功後**這台裝置**會記住，不用每次輸入。

- 密碼在編輯模式 →「前輩台」分頁可以改，也可以取消上鎖，或按「忘記這台裝置」讓它再問一次。
- 程式裡存的是密碼的雜湊（`config.locks.m6`），原本的數字不會出現在原始碼裡。
- **但這只是「防朋友順手偷看」等級的鎖**：遊戲是純前端，懂程式的人可以改瀏覽器的 localStorage 或直接讀程式繞過。真正要防，得等之後接帳號系統，由伺服器決定誰能進。

## 8. 每位前輩的台詞

`machine2.bossLines[前輩id]` 有六組，都可以放多句、隨機挑一句：`call`（找你談話）、`win`（約會成功）、`lose`（約會失敗）、`appear`（ST 出場）、`pass`（ST 通關）、`fail`（ST 失敗）。

`date`（約會對話）可以放**多套**，每套的行數就是約會的步數——抽到哪一套，約會就走那幾步。在編輯模式裡一行一套、用「｜」分隔每一步。

## 9. 開發者測試介面（編輯模式 →「前輩台」分頁）

| 按鈕 | 作用 |
|---|---|
| 好感度加滿 | 指定前輩或三位全部設成 100%（下次約會必定成功） |
| 累積機會牌 +5 | 指定前輩的累積數 +5（逼近保底） |
| 下一轉指定抽到 | 強制下一轉的小役（三種機會牌／銅鐘／空掘／碎石） |
| 約會（必成功／必失敗） | 直接跳進指定前輩的約會，結果先寫死 |
| 直接進報酬 10 轉 | 跳過前面，直接進 AT |
| 切換上位 | 直接開啟或關閉上位 |
| 直接進 BONUS | 指定 10／30／50／100／200 轉 |
| 重置這座礦坑 | 清掉累積與好感度 |

分頁上方會即時顯示目前狀態：state、三位的累積數、三位的好感度、對手、是否上位。這些在遊戲裡對玩家永遠不顯示。
