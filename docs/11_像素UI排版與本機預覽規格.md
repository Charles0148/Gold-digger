# 像素 UI 排版與本機預覽規格

- 日期：2026-09-27
- 狀態：IMPLEMENTED（2026-09-27 本機），待擁有者本機驗收；尚未發布。實作說明與截圖見 `Claude outputs/UI-preview-2026-09-27/README.md`。
- 目的：降低手機畫面擁擠，保留像素風、所有必要回饋與原本遊戲流程。

## 排版決策

1. 主導覽改為「挖礦／背包／地圖／老闆／紀錄」。紀錄頁包含「圖鑑／成就」兩個子分頁，保留原有收藏、信賴進度及內容；不實作準備中的新成就。
2. 礦坑名稱、當前階段和四項統計整合到中央場景的固定資訊區。中央保留礦石／演出內容；統計維持可見，不覆蓋結果或回憶文字。保留兩台各自原有的標籤與數值語義。
3. 當前事件、對話與操作提示最醒目；工具耐久與回合數次之；統計為輔助。保留手動／自動與離開的功能、確認及進度規則。
4. 保留 Cubic11、暗色底、方角、硬邊框與像素按壓效果。外層大區塊使用立體框，內層用間距、暗底或分隔線分組。保留既有稀有度、示唆顏色與彩虹事件意義；不得為統一配色抹掉遊戲訊號。
5. 導覽若加圖示，使用一致的像素圖示並保留中文標籤；不必為此購買或生成大型素材包。

## 挖礦文字與歷史

> **2026-09-28 擁有者決定（優先於本節下列舊條文）**：不做「近期訊息」也不做「本次紀錄」；挖礦敘述框只顯示這一次的結果。本節下列關於歷史的條文作廢。
> **2026-09-28 擁有者修正**：百次回憶時，中間展示框只顯示對話（不顯示資訊列、標題、外框），對話由上往下疊，超出的最舊對話從上方自然淡出消失。

- 普通挖礦畫面保留最近 2～3 筆事件摘要，最新一筆最清楚；重要結果、選項及工具損壞提示不能被舊訊息擠掉。這是筆數而非死板的三行文字，長內容需能完整讀取。
- 提供明確的「本次紀錄」入口，可展開查看近期歷史；與主導覽「紀錄」頁區別命名。歷史僅收集已向玩家顯示的資訊，不納入開發者抽選、隱藏設定或預定結果。
- 歷史以本次進入礦坑為範圍，採有限容量（建議最新 100 筆），顯示範圍說明。切頁不清空，真正離開／更換礦坑才開新段；不要求跨重整或雲端永久保存。
- 查看普通歷史時停止自動，關閉後由玩家自行恢復；捲動或關閉不能觸發挖礦。
- 舊訊息不保留閃爍或彩虹動畫，不能被誤認為本次期待度。正在進行的談話、ST、選擇等，仍以當前必要資訊為主。
- 百次回憶沿用已實作的固定順序、追加歷史與下方點擊繼續。需維持恢復、唯一發獎和接回報酬；不在此任務新增故事或永久重播系統。

## 第二台用語（2026-09-28 擁有者追加）

- 資訊列：第二台只顯示「本日」「累計」，不顯示「礦脈」「紫」。
- 不在畫面上顯示「上位」「報酬」「BONUS」：上位＝「已獲得最終認可」（看板獨立一行）、BONUS 轉數＝「前輩的心意 N」；看板不寫通關次數。
- 敘述框標籤顯示「第 N 次認可」（N＝通關次數）。
- 「ST」與「挑戰準備」顯示為「獲得前輩的認可吧！」（看板寫第 N 關）；「一轉定勝負」顯示為「自己的紅包 自己爭取」；談成功後的 AT 顯示「前輩帶路中」；進入前輩的心意後不顯示「累計」。

- 擁有者確認保持原樣：第一台「礦脈」「紫」；台詞「這次的報酬是 N 轉！」；看板「前輩的心意 N」不加「次」。

## 中文字級與手機適配

> **2026-09-28 擁有者決定**：移除「文字：標準／大字」設定，固定標準字級；本節關於大字的條文作廢。

- 以對話 17～18 CSS px、標籤 14～16px、輔助資料 13～14px、行距 1.55～1.7 為原型起點；依真實中文像素字顯示調整，不將這些數字當成已驗證標準。
- 提供清楚可找到的「文字：標準／大字」設定，優先放大閱讀內容，保存為本機顯示偏好；不加入自由拖拉縮放。預設保留像素字。易讀替代字型留待實測需要時提案。
- 主要點擊目標以至少 48×48 CSS px 為本機設計起點，相鄰操作保留約 8px 空隙。這不是把原生 pt／dp 直接當作 CSS px 的平台認證，仍須手機試點。
- 矮螢幕優先壓縮場景空白、裝飾與次要間距；對話和操作不可縮到難读。重要選項、工具狀態與繼續按鈕可到達；避免水平捲動和重疊。
- 保留安全區；大字時允許內容自然換行與必要的局部捲動，避免硬截字。平板先沿用中央單欄，不擴大成雙欄重構。
- 檢查現有主題／版面覆寫是否使新 CSS 失效，不可用清掉全部 localStorage 解決。

## 本機展示與截图交付

- 使用獨立本機測試存檔，在使用者電腦以 localhost 執行改好的真實遊戲。示範不得污染真實或雲端進度。
- 開工前保存一張目前主畫面作比較；改後截圖使用相同測試內容與尺寸。截圖為實際瀏覽器渲染，不用示意圖替代。
- 截圖目錄：`Claude outputs/UI-preview-2026-09-27/`；附一份簡短 README，寫預覽網址、啟動／停止方式、測試情境、尺寸、結果和仍待確認事項。
- 至少交付：改前與改後挖礦對照（390×844）；第二台談話／報酬；普通歷史展開；百次回憶中段與最後確認；紀錄頁兩個分頁；360×640 窄矮畫面的大字模式。以上尺寸為 CSS viewport，不宣稱真實手機驗證。
- 自行查看每張截圖，確認字型已載入、無遮擋溢出、當前回饋可辨識、操作區可見。另以長名稱、大額數字與長對話檢查邊界。
- 在交付訊息中直接列出預覽網址及截圖連結，讓擁有者能在電腦上試玩。若預覽無法維持運行，提供可直接執行的本機啟動方式並說明。
- 等擁有者看過實際畫面；未收到新的明確「上傳」指示，不能 push、部署或更改正式環境。
