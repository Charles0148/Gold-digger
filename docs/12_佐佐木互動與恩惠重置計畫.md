## 人物與演出原則

- 佐佐木認識現在及未來所有礦坑的人；有生活、人脈，也會依玩家幫忙的程度更友善。
- 生客→熟客→信得過的人。依已完成委託與恩惠等級調整口氣，精確門檻先作可調整的本機提案、在驗收表列明，不宣稱擁有者已定數字。
- 交易時全部是佐佐木單方面一句話，不要玩家回答、選對話或多按繼續；不得延遲買賣。
- 角色不會自動知道玩家私密經歷，不洩露岩倉性向或赤井家事。不把所有交易都寫成關係升級宣言。
- 台詞只能引用確實記錄過的事件；沒資料不能說「上回你弄髒鏡片」「又弄壞鎬子」。
- 每次最多一句情境台詞，定義優先序：操作結果／錯誤優先，其次關係里程碑，再來前輩閒聊與一般招呼。避免 render／數量滑桿讓台詞不停重抽。
- 前輩閒聊：（2026-09-28 改）只在確實離開前輩礦坑後第一次進店抽一次，詳見上方追加決定。
- 恩惠不等於可遺失的實體物品；「別弄丟」等不符效果的舊句一併修訂。

## 商店操作台詞方向（已同意，可整理成短句池）

| 觸發 | 生客／一般 | 熟悉後 |
|---|---|---|
| 進店 | 看看吧。要找什麼再叫我。 | 來啦？旁邊那張椅子沒壞，可以坐。 |
| 委託板 | 有把握再接，不用一次搬齊。 | 我就知道你會先看這張。缺什麼？我幫你瞧瞧。 |
| 賣礦石 | 放這邊，我秤一下。 | 今天這袋挺沉。你先歇著，我來。（須有足夠庫存；否則用不判斷重量的句子） |
| 買鎬子 | 拿起來試試，握得順比較要緊。 | 又把上一把用壞啦？拿來我看看，你是不是老拿它撬石頭。（僅確知工具損壞後） |
| 查看恩惠 | 之前答應你的，都記在這。 | 記著呢，少不了你的。你幫過我的忙，我還沒忘。 |
| 觀測鏡 | 鏡片別用手摸。來，往這邊看。 | 手先擦擦。我剛把鏡片擦乾淨。 |
| 領補給前 | 外頭在發工具，需要就去拿。 | 去拿一把吧。手上有備用的，心裡也踏實。 |
| 領補給後 | 拿到了？收好。 | 有了就別硬撐那把快斷的。省工具不是這樣省。（須有低耐久工具） |
| 離開 | 路上小心。 | 水帶了沒？……行，去吧。 |

- 委託第一次交付：「嗯，數量對了。錢拿好。」
- 開始熟悉：「你的東西放這邊就行。我先把這筆記完。」
- 熟客交付：「你辦事我放心。來，這是你的。」
- 整張完成：「齊了？好，這下不用到處找人問了。」
- 長期幫忙後整張完成：「今天又讓你跑了一趟。坐一下？我去添點水。」
- 初期升級：「這個給你。幫了忙，總不能只讓你拿一句謝謝。」
- 熟悉後升級：「替你留的。別客氣，我又沒說要收錢。」
- 已完成當期整張又看板：「今天的你都搬完了。怎麼，比我還急著開工？」
- 空背包：「空手也能進來。只是別擋著門，我這還要做生意。」
- 賣稀有礦：「先別倒！這顆另外放。……你在哪挖到的？」（修辭問句，不需玩家回答）
- 購買完成：「拿穩。用起來哪裡不順，下次跟我說。」
- 工具低耐久：「你那把柄都鬆了，還打算帶下去？」
- 交委託後馬上買工具：「錢還沒捂熱就花回來了。行，這把給你。」
- 短時間回店：「忘了什麼？」
- 久未進店：「有陣子沒見了。最近在哪座坑忙？」（不要求回答）
- 觀測結果資訊仍要準確，傾向與確定徽章不可混淆；不更改觀測機率。
